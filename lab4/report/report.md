## 4.1. Скалярное и внешнее произведения вектора

Создадим вектор `v`. Скалярное произведение вектора на себя вычисляется функцией `dot`, а внешнее произведение — произведением вектора-столбца на вектор-строку.

```julia
using LinearAlgebra

v = [1, 2, 3]
dot_v = dot(v, v)
outer_v = v * v'
println("Скалярное произведение: ", dot_v)
println("Внешнее произведение:")
display(outer_v)
```

Для выбранного вектора скалярное произведение равно \(1^2 + 2^2 + 3^2 = 14\). Внешнее произведение представляет собой матрицу \(3\\times3\):

\[
v v^T =
\begin{pmatrix}
1 & 2 & 3 \\\\
2 & 4 & 6 \\\\
3 & 6 & 9
\end{pmatrix}.
\]

## 4.2. Решение систем линейных уравнений

Системы записываются в матричном виде \(Ax=b\). Для совместной системы Julia находит решение оператором `A \ b`. Если у системы бесконечно много решений или она несовместна, это определяется по рангу матрицы коэффициентов и расширенной матрицы.

### 4.2.1. Системы с двумя неизвестными

Для каждой системы задаются матрица коэффициентов `A` и вектор правой части `b`. Проверяется совместность и количество решений.

```julia
using LinearAlgebra

systems2 = [
    ([1 1; 1 -1], [2, 3]),       # a
    ([1 1; 2 2], [2, 4]),        # b
    ([1 1; 2 2], [2, 5]),        # c
    ([1 1; 2 2; 3 3], [1, 2, 3]),# d
    ([1 1; 2 1; 1 -1], [2, 1, 3]),# e
    ([1 1; 2 1; 3 2], [2, 1, 3]) # f
]

for (i, (A, b)) in enumerate(systems2)
    println("Система ", ('a':'f')[i])
    println("rank(A) = ", rank(A), ", rank([A b]) = ", rank(hcat(A, b)))
    if rank(A) == rank(hcat(A, b))
        if rank(A) == size(A, 2)
            println("Единственное решение: ", A \\ b)
        else
            println("Бесконечно много решений")
        end
    else
        println("Решений нет")
    end
end
```

Результаты анализа:

- **а)** единственное решение: \(x=2{,}5,\ y=-0{,}5\);
- **б)** бесконечно много решений: \(x+y=2\);
- **в)** решений нет;
- **г)** бесконечно много решений: \(x+y=1\);
- **д)** решений нет;
- **е)** единственное решение: \(x=-1,\ y=3\).

### 4.2.2. Системы с тремя неизвестными

Аналогично исследуем системы с неизвестными \(x,y,z\). В системе (а) два уравнения и три неизвестных, поэтому при совместности решений бесконечно много.

```julia
systems3 = [
    ([1 1 1; 1 -1 -2], [2, 3]),       # a
    ([1 1 1; 2 2 -3; 3 1 1], [2, 4, 1]), # b
    ([1 1 1; 1 1 2; 2 2 3], [1, 0, 1]),  # c
    ([1 1 1; 1 1 2; 2 2 3], [1, 0, 0])  # d
]

for (i, (A, b)) in enumerate(systems3)
    println("Система ", ('a':'d')[i])
    println("rank(A) = ", rank(A), ", rank([A b]) = ", rank(hcat(A, b)))
    if rank(A) == rank(hcat(A, b))
        println(rank(A) == size(A, 2) ? "Единственное решение" : "Бесконечно много решений")
        if rank(A) == size(A, 2)
            println(A \\ b)
        end
    else
        println("Решений нет")
    end
end
```

Результаты:

- **а)** бесконечно много решений: при \(z=t\) получаем \(x=(5+t)/2,\ y=(-1-3t)/2\);
- **б)** единственное решение: \(x=-0{,}5,\ y=2{,}5,\ z=0\);
- **в)** бесконечно много решений: \(x+y=2,\ z=-1\);
- **г)** решений нет.

## 4.3. Операции с матрицами

### 4.3.1. Диагонализация матриц

Для симметричных матриц выполняется спектральное разложение \(A=QDQ^T\), где столбцы \(Q\) — ортонормированные собственные векторы, а \(D\) — диагональная матрица собственных значений.

```julia
using LinearAlgebra

matrices = [
    [1.0 -2.0; -2.0 1.0],
    [1.0 -2.0; -2.0 3.0],
    [1.0 -2.0 0.0; -2.0 1.0 2.0; 0.0 2.0 0.0]
]

for (i, A) in enumerate(matrices)
    F = eigen(Symmetric(A))
    println("Матрица ", ('a':'c')[i])
    println("Собственные значения: ", F.values)
    println("Диагональная матрица D:")
    display(Diagonal(F.values))
    println("Матрица собственных векторов Q:")
    display(F.vectors)
    println("Проверка A ≈ Q*D*Q': ",
        isapprox(A, F.vectors * Diagonal(F.values) * F.vectors'))
end
```

Для каждой матрицы выводятся собственные значения, диагональная матрица \(D\) и матрица собственных векторов \(Q\). Проверка разложения должна вернуть `true` с учётом вычислительной погрешности.

### 4.3.2. Степень и квадратные корни матриц

Вычислим десятую степень матрицы из пункта (а) и проверим существование вещественных квадратных корней матриц из пунктов (б–г). Для симметричной матрицы положительный квадратный корень можно построить по спектральному разложению, если все собственные значения неотрицательны.

```julia
using LinearAlgebra

A_a = [1.0 -2.0; -2.0 1.0]
println("A_a^10 =")
display(A_a^10)

function symmetric_sqrt(A)
    F = eigen(Symmetric(A))
    minimum(F.values) < -1e-10 &&
        error("Вещественного симметричного квадратного корня нет: есть отрицательное собственное значение")
    return F.vectors * Diagonal(sqrt.(max.(F.values, 0.0))) * F.vectors'
end

A_b = [5.0 -2.0; -2.0 5.0]
A_c = [1.0 -2.0; -2.0 1.0]
A_d = [1.0 2.0; 2.0 3.0]

for (label, A) in [("b", A_b), ("c", A_c), ("d", A_d)]
    println("Матрица ", label)
    try
        R = symmetric_sqrt(A)
        display(R)
        println("Проверка R^2 ≈ A: ", isapprox(R^2, A))
    catch e
        println(e)
    end
end
```

Для (а) результат:

\[
A^{10}=\begin{pmatrix}29525 & -29524\\\\-29524 & 29525\end{pmatrix}.
\]

У матрицы (б) собственные значения положительны, поэтому вещественный симметричный квадратный корень существует. Для (в) и (г) имеются отрицательные собственные значения, поэтому функция выше не строит вещественный симметричный квадратный корень.

### 4.3.3. Собственные значения и треугольная матрица

Для заданной матрицы \(5\\times5\) найдём собственные значения, диагональную матрицу собственных значений и нижнюю треугольную часть исходной матрицы. Для измерения времени используется макрос `@btime` из пакета `BenchmarkTools`.

```julia
using LinearAlgebra
using Pkg

# Выполнить один раз, если пакет ещё не установлен:
# Pkg.add("BenchmarkTools")
using BenchmarkTools

A5 = [140 97 74 168 131;
       97 106 89 131 36;
       74 89 152 144 71;
      168 131 144 54 142;
      131 36 71 142 36]

values = eigvals(Symmetric(A5))
D = Diagonal(values)
L = tril(A5)

println("Собственные значения: ", values)
println("Диагональная матрица:")
display(D)
println("Нижняя треугольная матрица:")
display(L)

println("Время вычисления собственных значений:")
@btime eigvals(Symmetric($A5))
println("Время построения нижней треугольной матрицы:")
@btime tril($A5)
```

Матрица `A5` симметрична, поэтому применяется `eigvals(Symmetric(A5))`. Функция `tril` оставляет диагональ и элементы ниже диагонали. `@btime` показывает оценку времени выполнения операции; значения зависят от компьютера и окружения.

## 4.4. Линейные экономические модели

Рассматривается модель \(x-Ax=y\), где \(A\) — матрица прямых затрат, \(x\) — вектор валового выпуска, \(y\) — вектор конечного спроса. При обратимости \(I-A\) решение имеет вид \(x=(I-A)^{-1}y\). В стандартном критерии продуктивности проверяют неотрицательность матрицы \((I-A)^{-1}\); спектральный критерий требует, чтобы спектральный радиус \(A\) был меньше единицы.

> Примечание: матрицы и множители ниже перенесены по распознанному тексту методички; перед сдачей сверьте их с исходным PDF, поскольку в скане дроби могут отображаться неразборчиво.

### 4.4.1. Проверка продуктивности по определению

Для каждого варианта вычисляется матрица \(B=(I-A)^{-1}\). Проверяем, что все её элементы неотрицательны.

```julia
using LinearAlgebra

M = [1.0 2.0; 3.0 4.0]
As = [M, 0.5 .* M, 0.1 .* M]

for (i, A) in enumerate(As)
    println("Вариант ", ('a':'c')[i])
    B = inv(Matrix{Float64}(I, size(A, 1), size(A, 2)) - A)
    display(B)
    println("Все элементы обратной матрицы неотрицательны: ",
        all(B .>= -1e-10))
end
```

### 4.4.2. Критерий обратимости

Для следующего набора матриц проверяем обратимость \(I-A\). Если определитель равен нулю или матрица численно вырождена, обратной матрицы не существует.

```julia
using LinearAlgebra

M2 = [1.0 2.0; 3.0 1.0]
As2 = [M2, 0.5 .* M2, 0.1 .* M2]

for (i, A) in enumerate(As2)
    B = Matrix{Float64}(I, size(A, 1), size(A, 2)) - A
    println("Вариант ", ('a':'c')[i])
    println("det(I-A) = ", det(B))
    println("Обратима ли I-A: ", abs(det(B)) > 1e-10)
end
```

Обратимость \(I-A\) является необходимым условием единственности решения модели для произвольного вектора спроса \(y\). Сама по себе обратимость ещё не гарантирует продуктивность — дополнительно проверяется знак обратной матрицы или спектральный радиус.

### 4.4.3. Спектральный критерий продуктивности

Вычисляем спектральный радиус \(\rho(A)\) — максимальный модуль собственных значений. Модель удовлетворяет спектральному критерию продуктивности, если \(\rho(A)<1\).

```julia
using LinearAlgebra

A_a = [1.0 2.0; 3.0 1.0]
A_b = 0.5 .* A_a
A_c = 0.1 .* A_a
A_d = [0.1 0.2 0.3;
       0.0 0.1 0.2;
       0.0 0.1 0.3]

for (label, A) in [("a", A_a), ("b", A_b), ("c", A_c), ("d", A_d)]
    rho = maximum(abs.(eigvals(A)))
    println("Вариант ", label, ": спектральный радиус = ", rho,
        "; продуктивна = ", rho < 1)
end
```

По критерию \(\rho(A)<1\) варианты (а) и (б) для матрицы `M2` не являются продуктивными, вариант (в) продуктивен; для трёхмерной матрицы (г) спектральный радиус равен \(0{,}3\), поэтому она продуктивна.
