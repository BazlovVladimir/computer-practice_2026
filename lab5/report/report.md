# Цель работы

Целью лабораторной работы является освоение средств построения и
оформления графиков на языке Julia с использованием библиотеки Plots.jl.
В ходе работы изучаются различные виды двумерной и трёхмерной
визуализации, параметрические кривые, поверхности, графики с
погрешностями, гистограммы, несколько осей координат и анимация.

# Задание

1.  Используя JupyterLab, повторить примеры из раздела 5.2, дополнив
    графики обозначениями осей координат, легендами, названиями
    траекторий и заголовками.

2.  Выполнить все задания для самостоятельной работы из раздела 5.4:
    построить различные типы графиков, оформить линии и оси,
    визуализировать экспериментальные и случайные данные, а также
    создать анимации.

# Выполнение работы

Работа выполнена в JupyterLab на языке Julia. Для построения графиков
используется пакет Plots.jl, для генерации случайных данных --- Random,
для статистических распределений --- Distributions, а для вычисления
средних значений --- Statistics. Ячейки ноутбука выполняются
последовательно.

Примечание к иллюстрациям: изображения оформлены в виде
реконструированных ячеек JupyterLab с соответствующими фрагментами кода
Julia и результатами построения графиков из ноутбука. Это не
необработанные снимки экрана работающего интерфейса; внешний вид
воспроизведён для единообразного оформления отчёта.
